BETA TESTER ACCESS // iOS + ANDROID

How to get the app on your phone.

This page is for beta testers. Pick your phone, install the build, and play. No ads. No in-app purchases. Online features use a random player id and device id.

INSTALL // PICK YOUR PHONE

iOS // TESTFLIGHT

iPHONE / iPAD

Install TestFlight from the App Store first, then join the beta. Open the link in Safari on your iPhone if it doesn’t open TestFlight on its own.

JOIN TESTFLIGHT →

Want the step-by-step guide? Open the tester page.

ANDROID // GOOGLE PLAY

ANDROID

Join the test on Google Play: join the testers group, tap Become a tester, then install StinkDoku from Play. Updates arrive through Play. Use one Google account for all three, and stay opted in and play for 14 days in a row.

BECOME AN ANDROID TESTER →

Can’t use Google Play? Download the APK instead (~9.4 MB sideload; Chrome: Settings → Install unknown apps → Allow). It won’t update on its own.
